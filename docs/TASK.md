# 开发任务：墙 MVP

完整需求见 `docs/PRD-v0.2.txt`（唯一范围来源，务必通读，尤其第 5、8、9、10、16 节）。在本目录实现完整 MVP，覆盖 D1–D8 全部功能。

## 技术约束
- 后端：Node.js（>=18）单进程 + `ws` 库。HTTP 用 Node 内置 `http` 提供静态文件，不用 express。
- 前端：`public/` 下原生 HTML/CSS/JS，Canvas 2D，不用框架、不用打包工具。
- 持久化：内存 Map + `data/rooms/{CODE}.json`，先写临时文件再 rename，写盘合并、最多每秒一次；启动时加载。
- 端口：环境变量 `PORT`，默认 3000。`npm start` 启动。
- 路由：`/` 门口页，`/w/:code` 墙页（同一个前端，按路径切换）。

## 必须实现的要点（PRD v0.2 的关键）
- 身份：客户端首次生成 clientId（crypto.randomUUID）存 localStorage，join 时携带；userId = clientId。昵称存 localStorage。
- 同一 clientId 的新连接顶替旧连接（旧页提示「已在别处打开」），不重复占席；断开 10 秒内未重连才广播「某某走了」并释放席位。
- 在线满 4 人拒绝第 5 人；颜色按顺序分配朱红/靛/松绿/琥珀，同 clientId 原色空闲则还原色。
- 房主 = 创建者 clientId；重连即恢复房主权。
- 画布 1600×1000，按 devicePixelRatio 创建；纸纹理底层 + 透明笔画层；橡皮在笔画层用 destination-out 真擦。
- 笔 3/8/18，橡皮 8/18/36；调色盘 = 本人主色 + 黑 #1A1A1A + 白 #FFFFFF + 灰 #868E96。文字工具字号 22，单行。
- 缩放：初始与「回正」= 适配可视区域；滚轮缩放到 200%；空格拖/中键拖平移。内部统一用画布坐标。
- 实时同步：stroke_start / stroke_point（打包）/ stroke_end；他人绘制过程实时可见；服务端在 stroke_start 时分配递增 seq，按 seq 绘制。断线或锁定时未完成的笔由服务端代为结束。
- 光标：节流 50ms，彩色点 + 昵称，3 秒不动半透明。
- 撤销/重做：只能撤自己的；撤销 = hidden 标记，重做恢复原层级；新笔清空自己的重做栈；上限 50；刷新后仍可撤销（服务端按 userId 推导）；清空后全员栈清零；锁定时非房主不可撤销。
- 快捷键：B/P 笔，E 橡皮，T 文字，[ ] 粗细，Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做，Esc。焦点在输入框时单键快捷键全部失效。
- 聊天：右侧约 280px 可折叠；Enter 发送，Shift+Enter 换行；≤200 字；保留最近 100 条；系统句（来了/走了/锁定/解锁/清空/被踢）样式弱化。
- 房主工具（顶栏 ⋯）：锁定/解锁；清空（全员 5 秒倒计时遮罩，房主可取消，服务端计时）；踢人（名单旁「请离」，被踢者回门口并提示）。
- 导出 PNG：任何人可导出整张 1600×1000 纸（含纸纹，不含 UI/光标），文件名 `墙-{CODE}-{时间}.png`。
- 重连：自动重连，底栏显示「重连中」；重连后拉全量 snapshot，离屏画好后一次替换，不闪白。
- 门口页：「砌一面墙」创建；输入 4 位码「推门」加入；空码/错码/满员中文提示。房间码字符集 ABCDEFGHJKLMNPQRSTUVWXYZ23456789。
- 视觉：按 PRD 6.4——暖灰桌面、暖白纸、无渐变无大圆角、工具选中态用本人主色描边、房间码用等宽字体。

## 测试（必须做）
- 写 `test/e2e.js`：用 `ws` 客户端直连服务器，至少覆盖：创建/加入、第 5 人被拒、同 clientId 顶替不占席、笔画广播与 seq、只能撤自己的、清空倒计时与取消、锁定后非房主不能画、踢人、重启服务后笔画仍在（持久化）。
